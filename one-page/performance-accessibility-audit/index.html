Website performance and accessibility audit

A clear report of what slows your site down or blocks people from using it, ranked by what matters most, and the fixes if you want them.

Who it's for: Teams and agencies with a live site that feels slow, scores badly on PageSpeed, or needs to be easier for everyone to use.

Get in touch See the proof

What you get

  • A performance review of real pages: images, fonts, scripts and layout shifts
  • An accessibility review: keyboard use, focus, contrast, headings, forms and screen reader basics
  • A prioritised list of fixes: what to do first and why
  • The fixes implemented, if you want them, in WordPress themes and blocks or in a custom frontend

How it works

  1. Scope

    We agree which pages and flows to review, usually the ones that matter most to your visitors.

  2. Audit

    I measure performance and test accessibility with automated tools and by hand.

  3. Report

    You get a short report in plain language, ranked by impact.

  4. Fix

    If you want, I implement the fixes and measure again.

Questions

Is a Lighthouse score enough?

No. Automated tools catch only part of the accessibility problems, so I also test by hand, for example with the keyboard.

Is this a legal compliance certificate?

No. It is a technical review, not legal advice or a certification.

Do you fix the issues too?

Yes, if you want. I can implement the fixes in WordPress themes and blocks or in a custom frontend, and measure again afterwards.
